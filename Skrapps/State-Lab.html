Five trits fit in a byte because 3⁵ = 243 ≤ 256: 7.92 of every 8 bits carry information (99.06%). That is a data encoding, not a three-voltage memory cell; the CPU still switches binary transistors.

·Radix economy

Cost of writing numbers in radix r if a digit costs r: proportional to r / ln r. The ideal is e ≈ 2.718, and 3 is the closest integer (5.6% better than 2). It is a classic argument for ternary hardware (Setun, 1958), not a property of binary CPUs.

02Operator atlas

·Unary operators

·What each one is

succ / pred: cyclic successor and predecessor; Pendashteh & Hosseini build them from four CNTFETs. In ꟻX: succ(x, R), pred(x, R).

os / ps: optimism and pessimism steps, one level up or down that stop at the ends (Mokhtari & Kabiri). In ꟻX: os(x, R), ps(x, R).

min / max: the MVL AND and OR. They form a lattice, not a field: there is no additive inverse, which is why the "field" claim in one supplied paper is not adopted.

sum digit / carry: the two outputs of a radix-R half adder; add a carry input and you have Zhao et al.'s ternary full adder (tab 03).

not: R−1−x, the standard MVL complement; on balanced trits it is negation.

In compiled ꟻX these operators are branch-free x86-64 (compare + conditional move, or vector min/max across 8–16 lanes in vectorized loops). They run on binary transistors; MVL energy savings need MVL hardware.

03Ternary ripple-carry adder

Zhao et al. (2024): a ternary full adder takes digits a, b and a carry c ∈ {0, 1} and gives sum = (a+b+c) mod 3, carry = ⌊(a+b+c)/3⌋. Step through the ripple from the least significant trit.

·Same adder, compiled

This is examples/mvl/ternary-adder.fx. It keeps the numbers in packed [trit; 39] arrays (8 bytes each), and the native program checks itself against binary addition.

let u = a[i] + b[i] + c; s[i] = u; // trit store wraps mod 3: the sum digit c = u / 3; // the carry digit

·Balanced ternary

Digits −1, 0, +1 (written −, 0, +) represent negative numbers with no sign bit; negating is flipping every digit. Setun (Moscow, 1958) computed this way. ꟻX's [btrit; N] stores these digits, five per byte.

A packed ꟻX array stores exactly the payload bytes above, so this declaration compiles to the same bytes in the program's data. fxc states source FILE.fxstates prints the same thing.

SHA-256 detects damage, not origin: anyone can recompute it. Treat a verified file as intact data, never as permission to run anything.

05Voltage threshold model

An idealized toy: R levels evenly spaced between 0 V and VDD, Gaussian noise, nearest-level decoding, 10,000 seeded trials. It is not a transistor-level circuit simulation (the CNTFET/GNRFET papers use HSPICE device models).

·Reading it

More levels in the same voltage span put the thresholds closer together, so the same noise causes more misreads. Real multilevel memory (MLC/TLC flash) pays for density with calibration, read-margin design and error correction.

No hardware voltage, power or error rate was measured. The model only compares radices at equal noise.
